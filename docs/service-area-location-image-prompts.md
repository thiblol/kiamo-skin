## TECHNICAL WORKFLOW

**Platform:** Google AI Studio (aistudio.google.com) or Gemini App (gemini.google.com) with Nano Banana Pro

**Generation Order:**
1. Generate Mission Hills first (establishes studio baseline aesthetic)
2. Upload Mission Hills output as reference image for all other locations
3. Prepend each subsequent prompt with: "Using the uploaded reference image, match its exact visual aesthetic, skin tones, studio environment, and lighting style. Change only the treatment modality and subtle mood to reflect the neighborhood described."

**Expected Results:** 80-90% visual consistency across all 9 images with treatment-specific variations

**File Naming Convention:**
- `hero-[area-name]-[primary-treatment]-[focus-concern]-san-diego.jpg`
- All lowercase, hyphens between words
- Max 60 characters including extension
- Geographic modifier at end before extension

**After Generation:**
1. Save images to `src/assets/`
2. Optimize with Astro's image pipeline
3. Import in service area page template:
   ```ts
   import heroLaJolla from '../../assets/hero-la-jolla-keravive-scalp-ocean-swimmers-san-diego.jpg';
   ```
4. Add Image component in page header before H1
5. Test build for proper optimization
6. Verify mobile rendering (4:5 portrait optimized for mobile-first)

**Image Specifications:**
- Orientation: 4:5 portrait (1080x1350px) for all location pages
- Orientation: 16:9 landscape (1920x1080px) for hub page only
- Format: JPG
- Quality: High (80-90%)
- File size target: < 500KB after Astro optimization
- Color profile: sRGB
- DPI: 72 (web optimized)
