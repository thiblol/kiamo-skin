## HOW TO USE

1. Paste the **Master Style Lock** block into Nano Banana Pro before any image in a session.
2. Generate **C-1 (Character Reference Sheet)** first — before any image with Kiki in it. Save the output
   and upload it to every subsequent portrait/action prompt. Add this instruction each time:
   *"Use the character from the reference image. Preserve exact skin tone, hair, and features. Change only pose, environment, and lighting."*
3. Generate **S-1 (Studio Reference)** second. Upload it to all interior and treatment-room prompts.
4. Each numbered prompt is **ready to copy-paste.** The *Variation* line gives you a second unique
   image from the same prompt without rewriting it.
5. **Nano Banana Pro rule:** write sentences like an art director brief — not keyword piles.
   One precise descriptor beats five vague ones.

**Posting strategy:** Upload 3–5 images per week to GBP. Spread across categories.
Google rewards consistent upload velocity — never bulk-drop 20 at once.
