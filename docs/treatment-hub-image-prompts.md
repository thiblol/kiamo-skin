1. Each prompt below is **100% copy-paste ready** — includes the Master Style Lock + specific image prompt.

### REFERENCE IMAGE WORKFLOW (CRITICAL)

Most prompts include a **REFERENCE IMAGE ATTACHED** note for the actual device used at KIAMO Skin (Keravive handpiece, Procell pen, dermaplaning blade, HydraFacial Syndeo wand, magnifying lamp, etc.). The AI does not know what these devices actually look like, so without the reference it invents a plausible-looking but wrong version.

**Per prompt, before pasting:**
1. Open Nano Banana Pro / Google AI Studio / Gemini.
2. Attach the reference photo(s) listed in the prompt's "REFERENCE IMAGE" note.
3. Paste the full prompt block.
4. Generate.

Without the reference attached, Nano Banana Pro will guess the device design and you'll get a generic-looking machine that does not match what KIAMO actually uses.
